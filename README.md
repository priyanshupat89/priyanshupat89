## Featured Projects

### SpiceVision: Hybrid Deep Learning for Spice Identification
**Problem:** Many spices look alike, which makes fine-grained visual classification hard.
**Approach:** Hybrid classifier for 20 spice categories using a frozen EfficientNetB3 backbone, CBAM attention and multi-scale feature fusion.
**Stack:** `TensorFlow` `Keras` `EfficientNetB3` `CBAM`
**Result:** **98.62% test accuracy** on the project dataset (self-reported, project dataset only).
**Links:** [Repository](https://github.com/priyanshupat89/REPLACE-WITH-REPO-NAME) · [Live demo](https://YOUR-PORTFOLIO-URL)

### STLC-Net: Skin Lesion Classification
**Problem:** Seven-class skin lesion classification on the HAM10000 dataset.
**Approach:** Compares transfer-learning backbones and combines them in an ensemble.
**Stack:** `Python` `PyTorch` `Transfer Learning` `HAM10000`
**Results (reported):** Ensemble 81.18% · DenseNet121 80.68% · EfficientNetB3 77.77% · MobileNetV2 75.74%
**Note:** Experimental research, not a diagnostic tool.
**Links:** [Repository](https://github.com/priyanshupat89/REPLACE-WITH-REPO-NAME) · [Live demo](https://YOUR-PORTFOLIO-URL)
